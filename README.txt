RePlate - Food Rescue Platform (PHP + MySQL, XAMPP)
1. Copy this folder to C:\xampp\htdocs\Replate
2. Start Apache + MySQL in XAMPP
3. Open http://localhost/phpmyadmin -> Import -> choose database.sql -> Go (creates DB "replate")
4. Open http://localhost/Replate/
Demo logins (password: password): admin@replate.com, donor@replate.com, ngo@replate.com, volunteer@replate.com
If MySQL has a password or the folder name differs, edit includes/db.php (DB_PASS, BASE).
Real photos: put a JPG/SVG with the same file name in assets/images/foods/ (names are in table foods.image).
